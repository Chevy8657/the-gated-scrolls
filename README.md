# Sovereign Node

The Sovereign Node is a static, deterministic web infrastructure layer designed
to support protocol-governed, district-level automation. It prioritizes
stability, predictability, and operational clarity over experimentation or
volatility.

## Architecture

- Fully static Next.js export
- No server-side runtime dependencies
- Deterministic builds and outputs
- Clear separation of surfaces (Home, Protocol, Recruitment, How It Works)

## Purpose

- Provide a stable operating surface for districts
- Standardize participation through documented Protocols
- Support structured recruitment and onboarding
- Maintain governance through explicit, versioned documentation

## Surfaces

- **Home** – Orientation to the Node and its role
- **Protocol** – Participation rules and tier definitions
- **Recruitment** – Agent and operator pathway
- **How It Works** – Architectural and operational overview
